## Папки
| Папка | Что там |
|---|---|
| `00-Inbox/` | быстрые мысли и цитаты с телефона, разбираем раз в неделю |
| `Books/` | одна заметка на книгу |
| `Articles/` | одна заметка на статью |
| `Ideas/` | одна мысль своими словами + ссылка на источник |
| `MOC/` | карты направлений, собираются автоматически (Dataview) |
| `Reviews/` | карточки для повторения (плагин Spaced Repetition) |
| `Templates/` | шаблоны: Book-nonfiction, Book-fiction, Article, Idea, Review |

## Цикл одной книги
1. **Начал** → новая заметка в `Books/` из шаблона, `status: reading`.
2. **Читаю** → мысли и цитаты кидаю в `00-Inbox/` или прямо в заметку. Маркером не увлекаюсь.
3. **Дочитал** → пишу Claude «обсудим [книга]»: сначала вспоминаю сам, потом вопросы и спор.
4. **По итогам** → заполненная заметка, 3–5 заметок в `Ideas/`, карточки в `Reviews/`.
5. **Раз в неделю** → 30 минут: ~15 на карточки, ~15 на обсуждение одной идеи.

## Плагины
- **Obsidian Git**: синхронизация с GitHub (`ky6ukpy6uka/library`)
- **Dataview**: таблицы в [[Dashboard]] и MOC
- **Spaced Repetition**: карточки из `Reviews/` по расписанию
- **Templates** (встроенный): папка шаблонов `Templates/`
