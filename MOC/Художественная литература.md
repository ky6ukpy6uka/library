# Художественная литература

Подбираем так, чтобы перекликалась с направлениями: выбор, власть, системы.

## Книги
```dataview
TABLE author AS "Автор", status AS "Статус", rating AS "Оценка"
FROM "Books"
WHERE contains(direction, "fiction")
SORT status ASC, rating DESC
```

## Идеи
```dataview
LIST
FROM "Ideas"
WHERE contains(direction, "fiction")
```
